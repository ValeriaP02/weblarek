## Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:  
`constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:  
`container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:  
`render(data?: Partial<T>): HTMLElement` - Главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.  
`setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

Конструктор:  
`constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:  
`baseUrl: string` - базовый адрес сервера  
`options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы класса:  
`get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер  
`post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.  
`handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:  
`_events: Map<string | RegExp, Set<Function>>` - хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:  
`on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.  
`emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.  
`trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

## Данные

### Интерфейсы данных

#### Товар IProduct

interface IProduct {
  id: string;            - Уникальный идентификатор товара
  description:           - string; Подробное описание товара
  image: string;         - Ссылка или путь к изображению товара
  title: string;         - Название товара
  category: string;      - Категория товара
  price: number | null;  - Цена товара (число или null, если цена не определена)
}

#### Покупатель IBuyer

interface IBuyer {
  payment: TPayment;     - Способ оплаты ('online' (онлайн) или 'on_delivery' (при получении), или undefined/ null, если способ оплаты не выбран)
  email: string;         - Электронная почта
  phone: string;         - Номер телефона
  address: string;       - Адрес доставки
}

### Модели данных

#### Класс каталог товаров ProductCatalog

Хранение товаров, которые можно купить в приложении.

Основные атрибуты:
`allProducts: IProduct[]` - массив всех товаров в каталоге.
`selectedProduct: IProduct | null` - объект выбранного в данный момент товара или null, если товар не выбран.

Методы класса:
`getAllProducts(): IProduct[]` - возвращает список всех товаров.
`saveProduct(product: IProduct): void` - сохраняет (добавляет или обновляет) информацию о товаре.
`getSelectedProduct(): IProduct | null` - получает информацию о выбранной карточке товара.
`setAllProducts(products: IProduct[]): void` - сохраняет (полностью перезаписывает) массив данных товаров.
`getProductById(id: string): IProduct | undefined` - получает один товар по его уникальному идентификатору (id). Возвращает undefined, если товар не найден.

#### Класс корзина Cart

Хранение товаров, которые пользователь выбрал для покупки.

Основные атрибуты:
`items: IProduct[]` - массив товаров, добавленных в корзину.

Методы класса:
`getItems(): IProduct[]` - возвращает список товаров в корзине.
`addItem(product: IProduct): void` - добавляет товар в корзину.
`removeItem(productId: string): void` - удаляет товар из корзины по его id.
`getItemCount(): number` - возвращает общее количество товаров в корзине.
`getTotalPrice(): number` - возвращает общую стоимость всех товаров в корзине.
`hasItem(productId: string): boolean` - проверяет, есть ли товар с указанным id в корзине.
`clearCart(): void` - очищает корзину (удаляет все товары).

#### Класс покупатель Customer

Данные покупателя, которые тот должен указать при оформлении заказа.

Основные атрибуты:
`payment: TPayment` - способ оплаты, выбранный покупателем.
`email: string` - электронная почта покупателя.
`phone: string` - номер телефона покупателя.
`address: string` - адрес доставки.

Методы класса:
`validateData(): boolean` - проверяет корректность введенных данных покупателя.
`saveData(buyerData: IBuyer): void` - сохраняет новые данные покупателя.
`getAllData(): IBuyer` - получает все сохраненные данные покупателя.
`clearCustomerData(): void` - очищает все данные, связанные с покупателем.

## Слой коммуникации CommunicationLayer

Класс, который будет взаимодействовать с сервером через API. Он будет использовать методы get и post из интерфейса IApi.

Методы класса:
`fetchProducts()` - GET-запрос на /product/, возвращающий массив товаров.
`sendOrder(orderData: IOrderData)` - POST-запрос на /order/, отправляющий заказ.

## Представления (View)

### Component

Базовый класс для всех компонентов представления. Предоставляет общие методы для работы с DOM-элементами.

Поля:
`container: HTMLElement`: Корневой элемент DOM, к которому привязан компонент.

Методы:
`render(data?: Partial<T>): HTMLElement`: Отрисовывает компонент, используя предоставленные данные. Возвращает корневой элемент компонента.
`setImage(element: HTMLImageElement, src: string, alt?: string): void`: Устанавливает атрибуты src и alt для переданного элемента изображения.

### Header

Представление для шапки сайта.

Поля:
`basketButton: HTMLButtonElement`: Кнопка корзины.
`counterElement: HTMLElement`: Элемент, отображающий количество товаров в корзине.

Методы:
`set counter(value: number)`: Сеттер для обновления счетчика товаров в корзине.

### Gallery

Представление для галереи товаров.

Поля:
`catalogElement: HTMLElement`: Контейнер, в который добавляются карточки товаров.

Методы:
`set catalog(value: HTMLElement[])`: Сеттер для добавления списка карточек товаров в DOM.

### BaseCard

Базовый класс для всех видов карточек товаров. Содержит общую логику для работы с элементами карточки.

Поля:
`titleElement: HTMLElement`: Элемент заголовка карточки.
`imageElement: HTMLImageElement`: Элемент изображения карточки.
`priceElement: HTMLElement`: Элемент цены карточки.
`categoryElement: HTMLElement`: Элемент категории карточки.

Методы:
`set title(value: string)`: Устанавливает заголовок карточки.
`set image(value: string)`: Устанавливает URL изображения карточки.
`set price(value: number | null)`: Устанавливает цену товара.
`set category(value: string)`: Устанавливает категорию товара.

### CardCatalog

Представление для отображения карточки товара в общем каталоге.

Поля:
`button: HTMLButtonElement`: Кнопка.

Методы:
`constructor(container: HTMLElement, onAddToCart?: () => void)`: Конструктор класса, принимает контейнер и опциональную функцию при добавлении товара в корзину.

### CardPreview

Представление для отображения карточки товара в режиме предпросмотра (в модальном окне).

Поля:
`text: HTMLElement`: Элемент описания товара.
`button: HTMLButtonElement`: Кнопка.

Методы:
`constructor(container: HTMLElement, onAddToCart?: () => void)`: Конструктор класса, который принимает контейнер и необязательную функцию обратного вызова onAddToCart. Он инициализирует элементы и добавляет обработчик события на кнопку.

### CardBasket

Представление для отображения карточки товара в корзине.

Поля:
`index: HTMLElement`: Элемент индекса товара в корзине.
`deleteButton: HTMLButtonElement`: Кнопка удаления товара из корзины.

Методы:
`constructor(container: HTMLElement, onDelete?: () => void)`: Конструктор класса, который инициализирует контейнер и элементы, а также добавляет обработчик события на кнопку удаления.

### BaseForm

Базовый класс для всех форм. Предоставляет методы для работы с полями формы, отображением ошибок и управлением кнопкой отправки.

Поля:
`submitButton: HTMLButtonElement`: Кнопка отправки формы.
`errorElement: HTMLElement`: Элемент для отображения ошибок валидации.

Методы:
`set enable(value: boolean)`: Устанавливает состояние кнопки отправки.
`set error(value: object)`: Отображает ошибки валидации.

### FormOrder

Представление для формы заказа (выбор способа оплаты и ввод адреса).

Поля:
`cardElement: HTMLButtonElement`: Кнопка выбора оплаты онлайн.
`cashElement: HTMLButtonElement`: Кнопка выбора оплаты при получении.
`addressInput: HTMLInputElement`: Поле ввода адреса доставки.

Методы:
`set payment(value: TPayment)`: Устанавливает выбранный способ оплаты.
`set address(value: string)`: Адрес доставки.

### FormContacts

Представление для формы контактов (ввод email и телефона).

Поля:
`emailInput: HTMLInputElement`: Поле ввода email.
`phoneInput: HTMLInputElement`: Поле ввода телефона.

Методы:
`set email(value: string)`: Устанавливает значение поля ввода email.
`set phone(value: string)`: Устанавливает значение поля ввода телефона.

### Modal

Представление для модального окна. Управляет видимостью окна и его содержимым.

Поля:
`closeButton: HTMLButtonElement`: Кнопка закрытия модального окна.
`contentContainer: HTMLElement`: Контейнер для размещения содержимого модального окна.

Методы:
`set show(value: boolean)`: Показывает или скрывает модальное окно.
`set content(value: HTMLElement)`: Заменяет содержимое модального окна.

### Success

Представление для модального окна с сообщением об успешном заказе.

Поля:
`title: HTMLElement`: Заголовок сообщения.
`description: HTMLElement`: Описание сообщения.
`closeButton: HTMLButtonElement`: Кнопка закрытия модального окна.

Методы:
`set cost(value: number)`: Устанавливает количество списанных синапсов.

### Basket

Представление для модального окна корзины.

Поля:
`listElement: HTMLElement`: Список товаров в корзине.
`priceElement: HTMLElement`: Элемент, отображающий общую стоимость товаров.
`orderButton: HTMLButtonElement`: Кнопка оформления заказа.

Методы:
`set cost(value: number)`: Установки общей стоимости.
`set products(items: HTMLElement[])`: Установки списка товаров.
`set enable(value: boolean)`: Включения или отключения кнопки оформления.

## Презентер

`basket:open` — Открывает модальное окно корзины. Собирает актуальный список товаров, вычисляет общую стоимость и рендерит компонент Basket.
`basket:close` — Закрывает модальное окно корзины.
`item:add` — Инициирует добавление выбранного товара в Cart.
`item:remove` — Инициирует удаление товара из CartModel по идентификатору.
`order:open` — Переход из интерфейса корзины к первому этапу оформления заказа. Рендерит форму FormContacts.
`contacts:close` — Сохраняет введенные данные (email, phone) в Customer. При отсутствии ошибок валидации переключает модальное окно на форму Order.
`order:close` — Сохраняет данные доставки (address, payment). При успешной валидации инициирует создание заказа через API, отображает Success.
`buyer:set` — Срабатывает при каждом изменении input в формах. Синхронизирует данные полей с моделью Customer.
`success:close` — Закрывает окно успешного заказа. Инициирует очистку корзины и сброс состояния заказа.
`modal:close` — Закрывает любое активное модальное окно, сбрасывает фокус и восстанавливает прокрутку страницы.

`catalog:productsUpdated` — Срабатывает после загрузки товаров с сервера. Презентер отрисовывает карточки в Gallery.
`catalog:productSelected` — Срабатывает при клике на карточку товара. Презентер инициирует создание CardPreview и отображает её в модальном окне.
`cart:itemAdded` — Срабатывает при добавлении товара в корзину. Презентер обновляет счетчик товаров в Header.
`cart:itemRemoved` — Срабатывает при удалении товара из корзины. Презентер обновляет счетчик товаров в Header.
`cart:cleared` — Срабатывает после полного очищения корзины. Презентер сбрасывает счетчик в Header до нуля.
`customer:dataUpdated` — Срабатывает при изменении данных покупателя в модели. Презентер синхронизирует значения во всех полях ввода (email, phone, address, payment) соответствующих форм.
`customer:cleared` — Срабатывает при сбросе данных покупателя. Презентер очищает поля ввода во всех формах оформления заказа.
